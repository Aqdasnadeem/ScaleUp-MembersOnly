# The two public files used in the fit test

They are not in this zip (one is 95 MB). Download them into a folder called `realsets`
NEXT TO this `fit` folder, then run `python fit_test.py` with the database env vars set.

```powershell
mkdir ..\realsets
curl -L -o ..\realsets\online_retail_II.csv https://raw.githubusercontent.com/omidreza-amrollahi/online_retail_data/main/online_retail_II.csv
curl -L -o ..\realsets\superstore.csv       https://raw.githubusercontent.com/muskaanpirani/Analysis_of_retail_store/main/SampleSuperstore.csv
curl -L -o ..\realsets\stock_codes.csv      https://raw.githubusercontent.com/omidreza-amrollahi/online_retail_data/main/stock_codes.csv
```

- `online_retail_II.csv` = UCI Online Retail II (1,067,371 rows, 2009-2011), a public dataset mirrored on GitHub.
- `SampleSuperstore.csv` = the trimmed Kaggle Superstore file (no order id, no date) - we use it on purpose as a file that cannot load.
- `stock_codes.csv` = product codes with a count, used as a file that is not an inventory file.

The shapes we wrote ourselves are generated by the script into `fit/shapes/`.
